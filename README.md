# Ultrasound Image Classification & Segmentation
This project is related to *Applied AI in Biomedicine* course at Politecnico di Milano. It deals with the development of two different approaches and of their comparisons based on Deep Learning. The project is divided into two tasks: the first requires to classify firstly the images and then proceed to segmentation; the second requires to segment firstly the images and then classify them. The context is the identification of lesions in the mammarian tissue.

# Time Series Prediction
This project is related to *Deep Learning & Artificial Neural Network* course at Politecnico di Milano. It requires to fit a Deep Learning model from time series data and make predictions on a testing set. The model components are resumed in the respective report.

# WSI Image Classification
This project is related to *Deep Learning & Artificial Neural Network* course at Politecnico di Milano. It deals with the training of a Deep Learning model which aims at classifying Whole Slide Imaging (WSI) images in different types of breast cancers. The architecture is resumed in the report.
